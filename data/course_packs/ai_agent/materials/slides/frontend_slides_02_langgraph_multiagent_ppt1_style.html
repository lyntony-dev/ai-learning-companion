Core Concept05 / 34
one sentence

LangGraph 是什么？

LangGraph 是把 Agent 工作流建模为有向状态图的编排方式：节点负责执行，边负责流转，状态负责承载上下文。

记住这一句：LangGraph = State + Node + Edge + Route。
State共享上下文
Node
执行单元
Edge
固定流向
Route
条件分支
Checkpoint
暂停恢复

根据 State 动态选路，是多 Agent 决策的关键。

Step 01 · State08 / 34
shared data

State 是图中流转的共享数据

每个节点读取 State、返回局部更新，LangGraph 负责合并并传递给下一个节点。

默认合并

返回值覆盖同名字段，适合 result、status、next_agent。

add_messages

消息列表追加，避免覆盖历史对话。

operator.add

列表或计数型字段可追加合并。

自定义 Reducer

为复杂结构定义任意合并逻辑。

Code · State09 / 34
minimum state

MessagesState 是最常用入口

教学重点：不要把 messages 写成普通 list，否则容易覆盖历史消息。

State 不是“全局变量”，而是图运行时被框架管理的数据快照。
state.py
from langgraph.graph import MessagesState class AgentState(MessagesState): next_agent: str research_data: str draft: str review_notes: str # messages 已内置 add_messages reducer
Step 02 · Node10 / 34
node concept

节点就是普通函数

不要神秘化 Node

输入 State

节点读取当前状态，包括 messages、草稿、评分、路由字段。

in

执行职责

节点内部可以调用 LLM、Agent、工具或确定性业务逻辑。

fn

局部更新

只返回需要更新的字段，未返回字段保持不变。

out

交给图流转

下一步由固定边、条件边或 Command 决定。

Code · Node11 / 34
node.py

一个节点的最小骨架

  • 函数参数是当前 AgentState。
  • 返回 dict 表示状态增量。
  • 不要在节点里隐藏复杂全局状态。
  • 错误处理和日志要靠外层工程兜底。

易错点

入口与出口必须清晰

  • 必须有 START 到某个节点的入口路径。
  • 至少要存在到 END 的可达路径。
  • 加 checkpointer 后可支持 thread_id、暂停恢复和持久化。

三种常见组织方式

Code · Command19 / 34
supervisor.py
def supervisor_node(state: AgentState) -> Command: response = llm.invoke([SYSTEM, *state["messages"]]) next_agent = parse_agent_name(response.content) if next_agent == "FINISH": return Command(goto=END) return Command( goto=next_agent, update={"next_agent": next_agent} )
Command 的价值

同时更新状态和指定跳转

相比把路由逻辑分散在条件边中，Command 更适合 Supervisor 这类“执行后立即跳转”的节点。

Context DI22 / 34
production architecture

用 Context 注入依赖，而不是全局变量

全局变量的问题

LLM、检索器、追踪器写在全局，导致难测试、难切环境、难追踪。

bad

Context 注入的优势

图编译时注入依赖，节点通过参数接收，测试时可替换 Mock 对象。

ctx
工程判断：Demo 可以简单，生产系统的模型客户端、Retriever、Tracing、配置应统一走 Context。

Human-in-the-Loop31 / 34
human checkpoint

在关键步骤暂停，让人确认后继续

适合发送邮件、审批、内容安全、评分发布等高风险节点。

interrupt(value)

暂停图执行，把待审核内容返回给调用方。

Command(resume)

人工确认后用同一个 thread_id 恢复执行。

checkpointer

保存暂停时状态，支持断点续跑。

业务价值

把高风险动作从“自动执行”改为“可控确认”。

Recap32 / 34
module recap

LangGraph 的核心价值是显式控制复杂性

  • State + Node + Edge 构成图。
  • Conditional Edge 让流程能根据状态动态分支。
  • Supervisor 是最容易落地的多 Agent 协作模式。
  • 循环工作流必须配合退出条件。
  • 生产系统要考虑 Checkpoint、Context DI 与 HITL。
