# ADR-0004：StateGraph 图分层——顶层 Router 主图 + 分能力子图 + 横切装饰

- 状态：已接受
- 日期：2026-07-16

## 背景

ADR-0001 已决定用真 LangGraph StateGraph 重写编排层。产品形态锁定为七大能力块（A 问答 / B Learner Model / C 个性化 / D 主动建议 / E 训练闭环 / F 结课项目陪练 / T 教学洞察）。这些能力需要挂到 StateGraph 上，图的组织方式决定可维护性、可测性，以及本轮"一条纵切贯通"能否干净落地。

候选形态：

1. **单一扁平主图**：所有节点挂一张图，靠 Router 条件边分流。节点一多条件边爆炸，E/F 的多步子流程会污染问答主链。
2. **主图 Router + 分能力子图 + 横切装饰**（本 ADR 采纳）。
3. **每块一张独立图 + 外层 Python 串联**：退回手写编排，违背 ADR-0001。

## 决策

采用**分层图**：

- **顶层主图**：只做意图路由（Router）+ 跨图共享 State 管理。Router 依 `task_type` 用 `add_conditional_edges` 分派到对应子图。
- **分能力子图**（LangGraph subgraph 嵌套，各自内聚节点与循环）：
  - **问答子图**：Retriever / Query Rewrite / Answer / Reviewer + 证据不足/评审的条件分叉与 `Rewrite→Retrieve` 回环（承载 ADR-0001 的图逻辑）。
  - **训练闭环子图**：出题 → 作答 → Grader 批改 → 更新掌握度（E 的最小一轮）。
  - **项目陪练子图**：里程碑状态读取 → 达标判定 → 建议（F 的里程碑状态机驱动）。
- **横切装饰（不单独成图）**：
  - **C 个性化**：画像注入——Retriever 前扩展检索范围到薄弱前置知识点，Answer prompt 注入掌握度深浅调节。
  - **D 主动建议**：会话开场 opener + 回答收尾建议，作为进入/退出装饰挂在主图边界。
- **TutorState**：作为顶层与所有子图的共享状态对象（TypedDict），跨图读写同一 State。

本轮纵切 = 主图 Router → 问答子图 → C/D 装饰，真实贯通并可测。

## 权衡

- **成本**：比单图多一层 subgraph 抽象；共享 State 字段需在主图与子图间约定清楚，避免字段漂移。
- **收益**：主图干净；子图可独立测试；能力边界与"引擎能力"划分一致；E/F 多步流程不污染问答主链；C/D 作横切避免重复建图。
- **被否决的方案**：形态 1（扁平图，条件边爆炸、子流程污染主链）、形态 3（外层手写串联，违背 ADR-0001）。

## 影响

- 编排层目录需按"主图 + subgraphs/ + 横切装饰"组织。
- 单测分层：主图路由测试、各子图独立测试、纵切集成测试。
- T 教学洞察是 per-course 聚合**只读模型**，不在 StateGraph 内（与写路径解耦），单独走读接口。
