# 产品愿景｜AI 学习伙伴 (AI Learning Companion)

> 本文是产品的北极星,是所有功能取舍与技术设计的最高标尺。当范围有争议时,回到本文。
> 状态:已与产品方确认(2026-07-16,Level 2 愿景)。它**取代**原 PRD "AI Agent 课程问答接口" 的产品定位,原 PRD 的功能条目降级为"AI Agent 课程包"的实现参考。

## 一句话愿景

> **做一个"学什么都陪你到会"的 AI 学习伙伴——它对每一门课都成立;我们从最懂的 AI Agent 课程开始验证。**

它 24 小时在线、认识你、陪你从"看懂"练到"做出来";同时让讲师看见教学、持续改进。

## 双层结构:学习引擎 + 课程包

这是本产品的**架构基因**,也是愿景放大的落点。

```
        ┌─────────────────────────────────────────┐
        │        学习引擎 (Learning Engine)          │  ← 领域无关、可复用
        │  陪伴 · 学习者档案 · 训练闭环 · 项目闭环 · 教学洞察  │
        └───────────────────┬─────────────────────┘
                            │ 加载
        ┌───────────────────┴─────────────────────┐
        │             课程包 (Course Pack)           │  ← 领域特定、可插拔
        │   资料/知识库 · 知识点体系 · Rubric · 结课项目   │
        └─────────────────────────────────────────┘
                            ▲
              第一个课程包 = 【AI Agent 课程】
              (LangChain / LangGraph / MCP / RAG 四门课)
```

- **学习引擎**：领域无关的能力——陪伴式对话、学习者档案(Learner Model)、训练闭环(出题→作答→批改→再出题)、项目闭环、教学洞察。换一门课，引擎不动。
- **课程包**：一门课的全部领域内容——资料与知识库、知识点体系(taxonomy)、评分 Rubric、结课项目定义。换课 = 换课程包。
- 所有"课程特定"的东西都被隔离进课程包；引擎里**不允许出现 AI Agent 专属的硬编码**。

## 第一落点(锋利性)

- **首个课程包锁定 AI Agent 课程**（四门：LangChain / LangGraph / MCP / RAG）。
- 愿景放大不改变 MVP 战场：MVP 仍然只把 AI Agent 课程包做透，用它把引擎打磨到真的有效。
- "可复制"体现在**架构解耦**上，不体现在 MVP 去接第二门课。第二个课程包是愿景的验证里程碑，不是 MVP 范围。

## 产品本质

把"一对一助教"这件昂贵、稀缺的事变成人人可得。它不是把课程内容搬上网(那是知识库)，而是复制出**"一个既懂这门课、又懂你的老师"**这个角色，并把这个角色做成一个**可换课程的引擎**。

系统服务**两类一等公民**：
- **学员** —— 被陪着学会、做出来。
- **讲师** —— 被辅助看清全班卡点、改进教学。

## 三个信念(愿景内核，领域无关)

1. **学习不是检索，是陪伴。** 服务的是**人**，不是问题。
2. **教得好的前提是认识你。** 个性化不是选项，是助教的定义本身。
3. **学会 ≠ 看完，而是做出来。** 每门课的终点都是一个能力产物(对 AI Agent 课 = 一个 Agent 工程)。

## 北极星指标

> **学员在所接入课程里完成结课项目的比例。**

不是问答量、不是 DAU。首战场用 AI Agent 课程衡量：**独立做出一个覆盖 LangChain / LangGraph / MCP / RAG 的项目**。

## 双主角价值

| 主角 | 产品为其解决什么 | 成功的样子 |
|---|---|---|
| 学员 | 卡住有人答、练习有反馈、课程内容能串起来做出项目 | 真正学会并完成结课项目 |
| 讲师 | 看清全班卡在哪、哪题错得多、下节课该讲什么 | 基于真实学情持续改进教学 |

## 边界(愿景不是什么)

- 引擎层：不是通用企业知识库，不是闲聊机器人，不是 MOOC 播放器；不做多租户商业化、组织权限治理、模型训练平台。
- MVP：只把 AI Agent 课程包做深，**不**在 MVP 内接第二门课；引擎与课程包解耦是设计约束，不是要立刻证明多课程。
